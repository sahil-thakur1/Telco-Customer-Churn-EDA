# Telco-Customer-Churn-EDA
Added a comprehensive Exploratory Data Analysis (EDA) project on the Telco Customer Churn dataset, including data cleaning, preprocessing, and transformation for accurate analysis. Implemented multiple visualizations to study customer behavior, service usage patterns, and churn distribution across different features such as internet services, contracts, and support options. Documented key findings and insights in the README to highlight major factors influencing customer churn and provide meaningful business recommendations for customer retention strategies. This update improves project clarity, usability, and demonstrates end-to-end data analysis workflow using Python and visualization libraries.
